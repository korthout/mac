# Example stand-ups

Nico picked these posted entries in `history/` as the reference for voice, length and tone. Read the `## Yesterday`, `## Today` and `## Blockers or risks` sections of each. Read the Multi-day example only when the window spans more than one working day or a P0 week.
- Match how they read, not what they cover.
- Take spacing from `rubric.md`, not from these files, because the archive doesn't reliably keep blank lines.

| Slot | File | Why it's the example |
|---|---|---|
| Short | `history/2026-09-29.md` | Readability first: a quiet day stays short, with one substantial bullet and one-line empty sections. It opens with a pointer to the previous late update instead of repeating it. |
| Broad | `history/2026-10-14.md` | A busy normal day. Every bullet states the substance (what was decided, who agreed, what is still open) with thread links. Today opens with a focus sentence. |
| Multi-day | `history/2026-10-12.md` | A window of several working days, including on-call work. It's long because the window is long. The point is compression: one bullet per stream of work (alerts, support cases, CI, CVEs), delegation stated in a clause, and only the deep investigation as its own bullet. |

## Swapping an example

A slot's example changes only when Nico agrees. Propose a swap (step 8 of `SKILL.md`) when today's posted entry fits a slot clearly better, for example because it shows the slot's point more clearly or because the current example now breaks a `rubric.md` line. Corrections during the run don't disqualify an entry: the posted text is the approved version. Add a new slot only for a case that keeps getting corrected and that no slot covers.
