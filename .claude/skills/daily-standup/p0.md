# P0 rules (medic and other on-call duties)

Read only when `rubric.md` points here.

- A medic or on-call P0 gets its own section only on the day(s) it applies, never in `p-tasks.md`. A P0 Nico names as a weekly P-task (e.g. a support case) stays in `p-tasks.md` and gets a `P0 -` section all week (2026-10-26).
- A multi-day P0 bullet is "Be first responder for incidents and support cases, delegating where it makes sense", not a case list.
- When Yesterday's activity clusters into a day of on-call-shaped work, propose a P0 even without a heads-up.
- A case delegated to Nico goes to `Also`. A teammate's bug is regular triage, not P0 (2026-10-05).
- In a medic week, fold bug issues, flaky-test fixes and CVE work into compact P0 bullets, but keep flaky tests apart from CI incidents. Only a deep investigation Nico root-caused stays its own `Also` bullet.
- A bullet clustering several CI incidents links each one as `[#inc-1234](url)`, an exception to plain `#channel-name`.
